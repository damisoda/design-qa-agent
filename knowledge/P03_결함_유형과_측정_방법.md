# P03 결함 유형과 측정 방법

작성: 조대흠, 2026-10-06. 에이전트가 보고하는 결함 유형, 측정 방법, 판정 기준이다. 예시 PR 번호는 팀 프로젝트 "돌아오길"의 실제 수정 PR이다(사례는 비공개 문서 C02에 있다).

## 반응형 결함

| 코드 | 유형 | 측정 방법 | 판정 기준 | 예시 |
|---|---|---|---|---|
| R1 | 넘침 | 자식 박스의 right(또는 bottom)와 부모 박스 비교, 글자 영역(Range)과 자기 상자 비교, 문서 가로 스크롤 폭 대 기기 폭. 의도된 가로 스크롤(한 줄 카드·스냅·표 감싸개)만 뺀다 | 자식이 부모 밖으로 2px 넘게 나감 | #221 인상착의 3칸이 줄 밖으로 넘침 |
| R2 | 잘림 | 글자 요소의 scrollHeight·scrollWidth 대 clientHeight·clientWidth, 작은 부모(버튼·탭·칩)의 overflow:hidden이 글자 영역을 자르는지 | 내용이 상자보다 커서 일부가 보이지 않음 | #190 탭 라벨 아랫부분 잘림 |
| R3 | 겹침 | 보이는 글자 영역끼리(여러 줄 글자는 줄마다), 글자와 얇은 막대, 글자와 배경·테두리가 있는 상자(스위치·카드)의 교차, 글자를 품은 칩·카드·버튼 상자끼리의 교차. 스크롤 영역에 잘린 부분, 덮는 층·시트 아래의 상자, 화면 끝 고정 막대나 떠 있는 버튼(FAB) 아래로 스크롤되는 내용(R4), 아이콘 위 배지처럼 일부러 얹은 장식, 잠깐 뜨는 알림(role=status 등)이 덮은 내용은 뺀다. 흐름 속 글자가 그림 위로 밀려 그림 픽셀과의 대비가 3:1 미만이어도 겹침이다 | 디자인에서 겹치지 않는 두 요소가 겹침 | #221 탭 라벨과 홈 인디케이터 막대 |
| R4 | 가려짐 | 요소 박스와 탭바·키보드·화면 아래 끝 비교, 화면의 40%보다 큰 아래 시트가 덮은 누를 요소(모달 대화상자는 뺀다), 머리글 아래에 고정한 넓은 막대가 덮은 첫 내용, 화면 높이로 고정된 틀 밖으로 밀려 스크롤로도 닿을 수 없는 버튼, 안전영역(노치·홈 인디케이터)에 들어간 글자 | 누를 요소가 다른 고정 요소나 화면 밖에 가려짐 | #160 CTA가 탭바에 가려짐, #215 입력칸이 키보드에 가려짐 |
| R5 | 크기 규칙 위반 | 화면 폭을 바꿔 가며 같은 요소의 폭 비교 | Fill인데 폭이 고정, Fixed인데 폭이 변함 | — |
| R6 | 원치 않는 줄바꿈 | 한 줄이어야 할 라벨(4자 이하)이나 띄어쓰기 없는 덩어리(가격·숫자, 20자 이하)가 두 줄 이상에 그려짐 | 디자인에서 한 줄인 글자가 여러 줄 | #221 "상의" 라벨이 세로로 꺾임 |
| R7 | 화면 틀 이탈 | 모달·시트·고정 요소(높이 24px 이상)의 박스와 앱 프레임 비교 | 앱 프레임 밖으로 확대되거나 벗어남 | #217 모달이 앱 프레임을 벗어남 |

## 상태 결함

| 코드 | 유형 | 측정 방법 | 판정 기준 | 예시 |
|---|---|---|---|---|
| S1 | 상태 누락 | 상태를 만든 뒤(누르기·비활성 조건·포커스) 계산 스타일을 기본 상태와 비교 | Figma 변형에는 차이가 있는데 구현은 그대로 | — |
| S2 | 상태 값 불일치 | 위와 같음 | 상태 스타일이 변형의 값(색·불투명도)과 다름 | — |
| S3 | 원치 않는 상태 표시 | 포인터로 누른 뒤 outline·box-shadow | 디자인에 없는 포커스 테두리 등이 보임 | #160 웹 탭을 누르면 파란 포커스 테두리 |
| S4 | 누를 수 없음 | 요소 중심점에서 elementFromPoint, 누른 뒤 화면 변화 | 다른 요소가 위를 덮어 눌리지 않음 | #159 모바일에서 탭이 안 눌림 |

## 디자인 시스템 결함

| 코드 | 유형 | 측정·확인 방법 | 판정 기준 | 예시 |
|---|---|---|---|---|
| D1 | 토큰 미사용 | 측정 색·크기가 토큰 값과 같을 때 코드 검색 | 토큰 값과 같은 값을 직접 씀 | — |
| D2 | 토큰 밖 값 | 측정값을 토큰 표와 대조 | 토큰에도 디자인에도 없는 값 | #209 빨간 CTA 색 정합성 |
| D3 | 타이포 불일치 | 계산된 font-family·size·line-height·letter-spacing을 Figma 글자 스타일과 대조 | 디자인 값과 다름(허용 오차 0.5px) | #193 #200 #208 타이포그래피 정밀 적용 |
| D4 | 에셋 품질 | 이미지 원본 해상도 대 표시 크기×기기 배율, 투명 픽셀 여부, 불러오기 실패(naturalWidth 0), 표시 비율 대 원본 비율(object-fit fill) | 1배 이미지가 2~3배 화면에서 확대되어 뭉개짐, 배경이 비침, 깨진 그림, 비율이 5% 넘게 늘어남 | #221 로고 PNG 흰 상자 |
| D5 | 시안 잔재 | 시안 전용 요소(상태바 시계, 홈 인디케이터)를 앱이 그리는지 | 실제 기기가 그리는 요소를 앱이 고정값으로 그림 | #162 상단 시계가 9:41로 고정, #190 가짜 홈 인디케이터 |

## 접근성 결함 (10-10 추가)

| 코드 | 유형 | 측정 방법 | 판정 기준 | 예시 |
|---|---|---|---|---|
| A1 | 작은 터치 영역 | 누를 요소(button·a·role=button/switch/checkbox/tab)의 상자 크기. 더 큰 누를 요소 안에 든 것과 글 속 링크(글자가 있는 링크)는 뺀다 | 24×24 CSS px 미만(WCAG 2.2 목표 크기 최소) | 합성 예제: 20px 찜 버튼, 20px 수량 버튼 |
| A2 | 낮은 글자 대비 | 글자색과 뒤 배경(가장 가까운 불투명 배경에 그 사이 반투명 배경을 섞은 색)의 명도 대비. `<img>` 위에 얹은 글자는 글자 아래 그림 픽셀과의 대비(중앙값)로 잰다. 그라데이션 배경 위 글자, 비활성 요소, 기호만 있는 글자는 뺀다 | 4.5:1 미만(24px 이상이거나 18.66px 이상 굵은 글자는 3:1, WCAG 1.4.3) | 합성 예제: #C9CDD2 안내 문구 1.6:1 |
