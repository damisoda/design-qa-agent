# 합성 Figma-HTML 예제

팀 앱과 다른 앱 6종(쇼핑 상품 상세, 배달 장바구니, 송금, 설정, 채팅, 데스크톱 대시보드)에 결함 24개를 하나씩 심은 예제다. 화면마다 아래를 둔다.

- 시안 명세 `screens/<화면>/design.json`: Figma 플러그인이 내보낼 모양이다. 프레임, 노드 트리, 오토 레이아웃(방향·간격·여백), 크기 방식(FILL·HUG·FIXED), 토큰 이름이 붙은 채움색과 글자 스타일, 모서리·테두리를 담는다.
- 시안 그림 `design.png`
- 맞게 만든 구현 `ok/index.html`
- 결함 변형 `<변형>/index.html`: ok와 CSS 한 줄이나 마크업 한 군데만 다르다.

| 유형 | 수 | 예 |
|---|---|---|
| R1 넘침 | 4 | 줄바꿈을 막은 긴 상품명, 줄어들지 못하는 쿠폰 입력칸, 단어 끊기를 뺀 긴 링크, 가로 스크롤을 뺀 표 |
| R2 잘림 | 2 | 폭을 고정하고 넘침을 숨긴 결제 버튼, 말줄임으로 잘린 버전 |
| R3 겹침 | 2 | 긴 설정 제목과 스위치, 4열로 고정한 KPI의 큰 숫자 |
| R4 가려짐 | 5 | 고정 막대 아래로 들어간 마지막 리뷰·메시지, 화면 밖으로 밀린 '다음' 버튼, 노치 아래로 들어간 제목 |
| R6 줄바꿈 | 2 | 좁은 칸의 '12,900원', 단어 끊기를 넣은 '1,250,000원' |
| A1 작은 터치 영역 | 4 | 20px 찜·수량·보내기 버튼, 30×18px 스위치 |
| A2 낮은 글자 대비 | 3 | 옅은 안내 문구·설명·표 머리글(1.6~1.9:1) |
| D4 그림 결함 | 2 | 늘어난 상품 사진, 깨진 프로필 그림 |
| D2 토큰 밖 색 | 1 | 구매 버튼 색이 토큰과 다름(Figma 비교가 있어야 잡는다) |

정답은 `verify_synth.js`가 확인한다. 선택자 기반 측정으로 결함 변형에서는 결함이 있고 같은 화면의 ok에서는 없는 크기만 정답으로 적는다. dqa 규칙은 쓰지 않는다. 크기에 따라 다르게 나타나는 결함은 그 크기만 정답이다. 예를 들어 긴 상품명은 320 폭에서만, '다음' 버튼은 320×568에서만 결함이다.

## 결과 (10-10, LLM 끔)

| | 규칙 범위 결함 23개 탐지 | 크기별 탐지 | 맞게 만든 화면 6개의 보고 | 결함 화면의 추가 보고 |
|---|---|---|---|---|
| 규칙을 늘리기 전 | 3 (13%) | 15% | 3건(모두 오탐) | 9건 |
| 규칙을 늘린 뒤 | 23 (100%) | 100% | 0건 | 9건(모두 같은 원인의 진짜 증상) |

- 늘리기 전 dqa는 팀 앱에 맞춰져 있어, 다른 앱의 결함을 거의 못 잡았다.
- 고친 것과 더한 것(`dqa/measure/inpage.js`)
  - R1: 세로 스크롤 영역을 "의도된 가로 스크롤"로 착각하던 것을 고쳤다. 글자가 자기 상자를 넘는 경우도 잰다.
  - R2: 작은 부모가 잘라내는 글자도 잰다.
  - R3: 스크롤 영역에 잘려 안 보이는 부분, 덮는 층 아래, 고정 막대 아래는 뺀다. 글자와 상자(스위치·카드)의 겹침을 더했다.
  - R4: 글자 태그를 후보에 넣었다. 닿을 수 없는 버튼과 안전영역 침범을 더했다.
  - R6: 띄어쓰기 없는 덩어리를 더했다.
  - 새 규칙: A1 작은 터치 영역(24px, WCAG 2.2), A2 낮은 글자 대비(4.5:1·3:1, WCAG 1.4.3), D4 깨진 그림·늘어난 그림.
  - 측정을 살리는 수정: 결함 조각 캡처가 실패해도 그 크기의 측정은 버리지 않는다.
- 같은 변경으로 실제 팀 앱 개발용 사례(#168·#217·#221)는 여전히 4/4다.
  - 추가로 늘어난 보고는 대부분 수정 전·후에 똑같이 있는 글자 대비 미달이다(예: 빨간 버튼 위 흰 글자 4.1:1). 시안 자체의 문제라 비교 검사에서는 "기존"으로 분류된다.
- 한계: 이 예제는 규칙을 고치는 데 썼으므로 개발용이다. 일반화 성능은 규칙을 고치지 않은 채 새로 만든 예제(다음 배치)와 실제 PR 평가용(#172·#190, 14주차에 연다)으로 재야 한다.
- 처음 만든 예제 판(화면 3개)은 팀 앱 화면과 이미 알려진 결함(#221·#227·#162·#217)을 본떠 새로 배우는 것이 없어 버렸다.
- 맞게 만든 시안의 색도 처음에는 WCAG 기준 미달이었다(밝은 하늘색 버튼 위 흰 글자 2.1:1). 기준을 넘는 색으로 바로잡았다.

## 다시 돌리기

```bash
python3 eval/synth/make_synth.py          # 화면·변형·cases.json
node eval/synth/verify_synth.js           # 정답 확인(verified), shots/
node eval/synth/export_design.js          # 시안 명세 design.json, design.png
node eval/synth/grade_synth.js --tag synth2-after
```
